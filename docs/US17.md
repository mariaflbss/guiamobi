# US17 — Notificações sobre alterações nas linhas

## Entrega

A US17 adiciona:

- tela `Configurações > Notificações`;
- ativação/cancelamento de notificações push, com estado persistente por usuário;
- inscrição e cancelamento de inscrição por linha, com atualização imediata na tela;
- persistência local das escolhas e sincronização complementar com o PostgreSQL;
- registro do dispositivo para Expo Push quando o token remoto estiver disponível;
- consulta automática periódica de Service Alerts GTFS-Realtime, independentemente da tela de notificações estar aberta;
- entrega somente para usuários inscritos na linha afetada;
- proteção contra entrega duplicada do mesmo alerta por usuário e linha.

## Observação sobre Expo Go

A tela e o controle de permissão podem ser validados no Expo Go. O token de push remoto do Android deve ser validado em um development build/nativo; o aplicativo não deve travar se o ambiente atual não fornecer esse token.

## Critérios de aceite

1. Alterações de trajeto, desvios e interrupções podem gerar notificações para as linhas inscritas, durante ou fora da navegação.
2. O usuário consegue cancelar a inscrição de notificações push e cancelar inscrições individuais de linhas.
3. O sistema direciona os alertas somente para as linhas em que o usuário está inscrito.


## Correções finais de compatibilidade
- O schema Prisma possui as relações inversas de `TransitLine` necessárias para gerar o Prisma Client.
- A tela não depende da resposta da API para manter as escolhas do usuário visíveis: ativação, cancelamento e inscrições permanecem persistidos localmente.
- Falhas de sincronização remota não desfazem uma ação que o usuário acabou de realizar; a sincronização é repetida posteriormente.
- O handler de notificações é configurado na inicialização do aplicativo, permitindo receber alertas durante e fora da navegação.
- O aplicativo não cria canal Android manualmente no Expo Go; a tela permanece utilizável nesse ambiente.
- O registro remoto de push continua dependente de um development build nativo quando o Expo Go não fornece token.
- A rotina automática de Service Alerts evita execuções sobrepostas e consulta cada linha uma única vez por ciclo.
